## Steps

1. `newsmlg2.gemspec` — copy chemicalml's, changing:
   - name `newsmlg2`, `spec.version = Newsmlg2::VERSION`
   - summary: "NewsML-G2 — IPTC News Architecture (NewsML-G2) for Ruby."
   - description: "Newsmlg2 provides a lutaml-model-based Ruby object model for IPTC
     NewsML-G2 (NAR). Parse, manipulate, build and serialize NewsML-G2 XML with
     full round-trip fidelity, including a builder DSL."
   - homepage / metadata URIs: `https://github.com/lutaml/newsmlg2-ruby`
   - keep `required_ruby_version >= 3.3.0`, `add_dependency "lutaml-model", "~> 0.8.0"`,
     BSD-2-Clause, Ribose Inc. (these mirror the reference gem per project decision).
2. `Gemfile`:

   ```ruby
   # frozen_string_literal: true

   source "https://rubygems.org"

   gemspec

   gem "rake", "~> 13.2"

   group :development do
     gem "canon"
     gem "nokogiri"
     gem "rspec", "~> 3.13"
     gem "rubocop", "~> 1.66", require: false
     gem "simplecov", "~> 0.22", require: false
   end
   ```

3. `Rakefile` — identical to chemicalml's (bundler/gem_tasks + rspec task, default `:spec`).
4. `.rubocop.yml` — copy chemicalml's; keep the `lib/newsmlg2/base/**/*` metric
   exclusions (the `Base::*` mixins will be long) and `Style/Documentation: Enabled: false`.
5. `.gitignore` — copy chemicalml's verbatim.
6. `lib/newsmlg2.rb` — module `Newsmlg2` with `autoload :VERSION, "newsmlg2/version"`
   and a docstring; `require "lutaml/model"`.
7. `spec/spec_helper.rb` — base version now (requires `newsmlg2`, sets
   `Lutaml::Model::Config.configure { |c| c.xml_adapter_type = :nokogiri }`,
   standard RSpec settings as in chemicalml). Canon configuration will be added
   in plan 10 when comparison matchers are first used.
8. `spec/newsmlg2/version_spec.rb` — asserts `Newsmlg2::VERSION` is a semver string.
9. Workflows — create verbatim:

   `.github/workflows/rake.yml`:

   ```yaml
   # Auto-generated by Cimas: Do not edit it manually!
   # See https://github.com/metanorma/cimas
   name: rake

   permissions:
     contents: write
     packages: write

   on:
     push:
       branches: [ master, main ]
       tags: [ v* ]
     pull_request:

   jobs:
     rake:
       uses: metanorma/ci/.github/workflows/generic-rake.yml@main
       secrets:
         pat_token: ${{ secrets.LUTAML_CI_PAT_TOKEN }}
   ```

   `.github/workflows/release.yml`:

   ```yaml
   # Auto-generated by Cimas: Do not edit it manually!
   # See https://github.com/metanorma/cimas
   name: release

   permissions:
     contents: write
     packages: write
     id-token: write

   on:
     workflow_dispatch:
       inputs:
         next_version:
           description: |
             Next release version. Possible values: x.y.z, major, minor, patch (or pre|rc|etc).
             Also, you can pass 'skip' to skip 'git tag' and do 'gem push' for the current version
           required: true
           default: 'skip'
         acknowledge_breaking_in_patch:
           description: 'Override the patch-release breaking-change guard when the trip is a known false-positive'
           required: false
           type: boolean
           default: false
     repository_dispatch:
       types: [ do-release ]

   jobs:
     release:
       uses: metanorma/ci/.github/workflows/rubygems-release.yml@main
       with:
         next_version: ${{ github.event.inputs.next_version }}
         acknowledge_breaking_in_patch: ${{ inputs.acknowledge_breaking_in_patch }}
       secrets:
         rubygems-api-key: ${{ secrets.LUTAML_CI_RUBYGEMS_API_KEY }}
   ```

   `docs.yml`, `links.yml`, `opal.yml`, `performance.yml` are added in plan 14,
   when their prerequisites (docs site, opal/performance rake tasks) exist.

10. `LICENSE` — BSD-2-Clause text, copyright Ribose Inc., as in chemicalml.
